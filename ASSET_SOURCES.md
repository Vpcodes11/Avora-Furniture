# Asset sources

The active AVORA design uses original generated furniture imagery: the Arc, Shell, Conch, architectural room, and transparent Arc image. The layered room presentation and pointer parallax are built with CSS and JavaScript. The spatial gallery's exhibition architecture, frames, lighting, and sculptures are original Three.js geometry; framed images use the same original furniture artwork.
